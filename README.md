## 🛠️ Tech Stack & Latest Web Trends

* **Web Audio API + AudioWorklets:** Handles real-time sound generation and professional filtering directly inside the browser. It executes heavy audio synthesis on a separate background thread (`AudioWorkletGlobalScope`) to guarantee absolute zero system latency.
* **Transformers.js:** Powers a lightweight, hardware-accelerated neural network model running locally on-device to predict mental distraction metrics without external servers.
* **Tailwind CSS & Canvas API:** Drives pixel-perfect responsive layouts utilizing responsive grid architecture and fluid 60fps animations.

## 📊 Live Control Deck Metrics

The engineering dashboard evaluates your workflow through five precise live indicators:
1. **Flow State:** Measures rhythmic, sustained keystrokes; higher implies deeper immersion.
2. **Focus Score:** A composite metric calculating the absolute ratio of flow vs. distraction risk.
3. **Kinetic Tempo (BPM):** Real-time engine pace tracking user interface activity velocity.
4. **Stress / Tension:** Automatically flags erratic cursor jitter and sudden, bursty keystroke patterns.
5. **Distraction Drift:** Detects idle timeline gaps and scattered, low-rhythm computer activity.
